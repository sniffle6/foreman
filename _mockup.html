Two projects snapped side-by-side — with the custom titlebar

Snapping two projects isn't "full-screen" (one thing filling the window), so the titlebar-merge is ambiguous here. Two ways it can resolve:

Option 1 · Snap = tiled windows → each keeps its own header (titlebar stays bare)

Merge only applies to a single full-screen project. Two snapped projects behave like today's tiling — each tile carries its own tab-strip header. Cost: the top titlebar is bare/wasted while tiled, and you still have two header rows per tile (project + terminal).

Option 2 · Titlebar splits to match the tiling → no per-project header rows

The titlebar divides into zones aligned with the tiles — left half is `api`'s tabs+keys, right half is `web`'s — so each project's chrome lives up top and the content is full-bleed. The window's min/max/close stay in the far-right corner. Cost: the seam/zone alignment and the right zone sharing the corner with the window controls.
