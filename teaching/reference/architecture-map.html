Asset naming (single definition)

zip:        foreman-v{VERSION}-x86_64-windows.zip
checksums:  SHA256SUMS.txt          (<hex>  <filename> lines)
installer:  foreman-v{VERSION}-setup.exe   (deferred)

CI writes full names. Consumers only match suffixes (e.g. ends-with -x86_64-windows.zip) over the release's asset list — select_asset() in Rust, pure and unit-tested. Nobody reconstructs a filename from a version string.

The updater does not consume this seam — it keys off current_exe(). That's why portable installs self-update too.

Updater state machine (pure core)

decide(current_version, release_json) -> Decision      // semver + select_asset
step(State, Event) -> (State, Vec<Effect>)             // ALL transitions live here

States:  Idle
         UpdateAvailable { version, can_apply }   // chip ↓ v0.2.1
         Downloading { progress }                 // P4
         ReadyToRestart                           // P4: "Restart to update"
         Error { retryable }

Events:  ReleaseFetched | FetchFailed | ClickChip | Progress
         HashOk | HashBad | SwapOk | SwapFailed | ClickRestart

Effects: FetchLatest | OpenReleasesPage | Download
         VerifyAndSwap | SaveWorkspaceAndRestart

The background thread is a dumb adapter: executes Effects, feeds Events back over a channel + repaint — the same seam shape as Session's PTY reader thread. egui renders the state and forwards clicks. Unit tests hit step/decide directly (layout/wm/chat convention).

Glossary

Manifest
The machine-readable answer to "what is the latest version and where do I get it." Foreman's manifest is the GitHub Releases API itself, not a file we maintain.
Mark-of-the-Web (MotW)
A hidden NTFS stream (Zone.Identifier) tagging a file as internet-sourced. Browsers and Explorer-zip-extraction write/propagate it; Invoke-WebRequest and Expand-Archive don't. Verified empirically 2026-07-15.
SmartScreen
Windows' reputation check, triggered only for MotW-tagged executables. No MotW → no scary dialog. Why the irm|iex path is frictionless without code signing.
Rename-swap
The self-update trick: Windows forbids deleting/overwriting a running exe but allows renaming it. Rename running→.old, slide .new into place. rustup's mechanism (see self-replace).
Seam
A place where behaviour can vary without editing there. The install layout is a seam: script and Inno are adapters writing the same facts.
Pure core / thin adapter
All decisions in pure functions (step, decide); all I/O in a thread that just executes Effects. Tests exercise the shipping logic, not a shadow copy.
Silent-skip
Background-check failures (offline, rate-limit, corporate TLS proxy) log and retry later — never a visible error.
Cold restore
Foreman's workspace persistence: save on exit, rebuild sessions on launch. What makes "restart to update" cheap.
