What this is

Three states of one confirm modal, shown at foreman's real dim level (rgba(0,0,0,.588)) over a mock desktop. Minimal pass: flat single surface, no glyph, no pips, one accent.

Skinned to the steel + safety-orange direction from mocks/toolbar-concepts.html. theme.rs still holds the warm palette — the real modal inherits whatever tokens exist when built.

Palette

steel-0 steel-1 steel-2 orange ink-dim

Safety orange is the single accent — it carries the confirm action (the "proceed with caution" button) and nothing else in the modal.

Interaction

Fires only when the shell has a real child (agent, build, REPL, server). Idle prompt closes with no modal. OpenConsole.exe plumbing is filtered out. Esc cancels; Enter confirms.

Open decisions

Default button. close anyway is default (Enter confirms), like Windows Terminal. Safer alt: default to cancel.
Group by terminal. Toggle above. Grouped needs each process tagged with its terminal — a small extension to the flat list the spec has today.
