# Phase 0 protocol — paste-simulation fingerprint probe (FROZEN)

Status: **FROZEN 2026-07-12, before any probe run.** Do not edit this file or
`phase0_predict.py` after the first probe executes; corrections go in the
results doc with a pointer back here. Design context:
`docs/superpowers/paste-sim-rework.html` (local page, four review passes).

## What this decides

Whether the dual-simulation acceptance predicate can cover the
**hard-positioned** PSReadLine paste variant (`docs/wide-chars.md`
"Residual variant") — the claim every review flagged as argued-not-measured.
A green result establishes feasibility **on these frozen fixtures only** —
not global safety, and not permission to delete the CUP scanner.

## Prediction model (frozen in `phase0_predict.py`)

- **E** (whole-glyph): unicode-width per char; lazy pending-wrap before the
  next char; width-2 at the last column pads (`LEADING_WIDE_CHAR_SPACER`)
  and defers; cursor never occupies `col == cols`.
- **P** (PSReadLine 2.4.5): per UTF-16 unit; non-BMP char = two width-1
  units; **Assumption A1** (highest-risk): `x == cols` rolls immediately to
  `(0, y+1)`; no pads.
- **Tail-fingerprint anchor**: last non-space glyph of the payload
  (trailing spaces read as empty cells).

**Blindness rule (S2):** its capture file is written but **not opened, not
parsed, not summarized** until P's model is declared final. If A1 or any
part of P is revised from S1's bytes, the revision is graded on S2's
untouched capture. A holdout-informed revision does not count as validation.

## Pre-registered outcomes

| # | Observation (primary) | Verdict |
|---|---|---|
| O1 | settled raw column == P col; oracle actual_end == raw + delta; fingerprint present; predicate fires | **green** — feasibility on fixtures |
| O2 | raw == P but oracle actual_end ≠ raw + delta (e.g. `U+FFFD` corruption cells displace the end) | fail-closed coverage loss — document; rework may still proceed for the pad variant only |
| O3 | settled raw ≠ P | **kill-switch** — refine P from S1 bytes and grade on S2 blind, or park with the negative recorded |
| O4 | predicate would accept at any byte offset where the oracle disagrees with E′ | **safety refuted** — predicate redesign before any spec |
| O5 | S3 arms or aliases | model or gating bug — fix before interpreting S1/S2 |

O4 is evaluated by replay: feed the framed capture **byte-at-a-time** into a
`Term<VoidListener>`, evaluate the full acceptance predicate after every
byte (every possible chunk boundary), log each CUP's byte offset with
pre/post cursor.

## Oracle (independent of the predicate)

`actual_end` = scan the full viewport bottom-up for the last cell that is
not a space and not flag-empty; report its point and the one-past point.
Additionally dump, for the last three content rows: per-cell char, width
flags, `Cell::is_empty()`, and per-row WRAPLINE — so spacer identity and
packing are measured, not assumed.

## Harness

Release-mode `#[ignore]`d diagnostic test(s) in `src/terminal.rs` tests
(same fixture family as `live_psreadline_paste_wrap_uses_the_whole_emoji_endpoint`):
records pre-paste raw cursor + `input_needs_wrap` + `history_size`; captures
every RX chunk as **typed, length-framed records** to
`%TEMP%\phase0-<scenario>.bin` (raw `rx_dump` is unframed — unusable);
settles; dumps the oracle readout and raw vs renderable cursor as JSON lines
to stdout. No production-path changes of any kind.
