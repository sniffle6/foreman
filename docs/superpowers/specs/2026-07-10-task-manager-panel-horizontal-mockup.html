Rail — 36px strip; icons flow left-to-right; no header band, expand glyph rides the right end

Implementation notes

  • The rule: in PanelView::show, pick flow by the content rect it is already given each frame — rect.width() > rect.height() → horizontal. No new state, no persistence: move the leaf back to a tall slot and it flips back. Discrete per-frame check; no hysteresis needed since tree moves are atomic.
  • Same row painter. Columns mode reuses paint_row verbatim — only the cursor advance changes (y within a 200px-wide group, x between groups). Truncation budget per row comes from the group width instead of the panel width.
  • Strip threshold: when rect.height() can't fit the project row plus one tab row (~48px), fall to chips. Chips keep click = surface; min/close hover buttons only in columns mode (chips are too small — right-click or expand for management).
  • Collapsed + horizontal: set_leaf_width pins width today; a bottom-docked collapsed panel needs the same pin on height — generalize to set_leaf_extent along the split axis before shipping this.
  • Scroll axis flips with the flow: smooth_scroll_delta.y drives x-offset in horizontal mode (mouse wheels have no x axis).
