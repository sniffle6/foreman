Design intent (implementation notes)

  • Quiet chrome: no title fill — body is WIN_BG / terminal BG; focus from border + text, matching docs/window-chrome.md.
  • Panel header has collapse only — no min/max/close (window is non-closable / non-minimizable).
  • Row density ~22px, crew-board-ish; project rows full width, tabs indented ~16px.
  • Icons reuse existing tab-strip IconKind (folder / Claude / Codex / shell / chat).
  • No agent-state badges in v1 — rail leaves a reserved slot for future dots.
  • Bottom-left chips are gone (Task 7); ghost toggle only shows what is deleted.
